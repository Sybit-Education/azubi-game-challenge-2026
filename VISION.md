# Spiel Vision

## Phase 1: Projekt verstehen

### Ziel

Versteht gemeinsam, was gebaut werden soll.

Am Ende dieser Phase soll jeder beantworten können:

- Wie funktioniert das Spiel?
- Wer spielt es?
- Wie verbinden sich die Smartphones?
- Was bedeutet Accessibility im Projekt?

### Aufgaben

- Vorjahresprojekt anschauen
- Phaser-Tutorial durcharbeiten
- Socket.IO-Grundlagen verstehen
- Gemeinsames Spielkonzept festlegen
- Rollen im Team verteilen

### Ergebnis

- Skizze des Spiels
- Technisches Konzept
- Erste Aufgabenliste im GitHub-Backlog

---

## Phase 2: Technisches Grundgerüst erstellen

### Ziel

Alle Geräte können sich miteinander verbinden.

### Aufgaben

#### Großbildschirm

- Phaser-Projekt starten
- Hauptszene anzeigen
- Lobby erstellen

#### Smartphone

- Mobile Webseite erstellen
- Spielername eingeben
- Verbindung zum Spiel aufbauen

#### Backend

- Socket.IO einrichten
- Spieler verbinden
- Lobby verwalten

### Ergebnis

- Spieler können beitreten
- Alle Teilnehmer werden auf dem Hauptbildschirm angezeigt

---

## Phase 3: Erste spielbare Version

### Ziel

Eine komplette Runde muss spielbar sein.

### Aufgaben

- Runde starten
- Aufgaben an Spieler verteilen
- Eingaben vom Smartphone verarbeiten
- Punkte vergeben
- Spielende anzeigen

### Ergebnis

Ein spielbarer Prototyp.

Wichtiger als Perfektion:

> Das Spiel muss Spaß machen.

---

## Phase 4: Accessibility integrieren

### Ziel

Das Spiel soll möglichst vielen Menschen zugänglich sein.

### Aufgaben

#### Smartphone

- Alle Buttons beschriften
- Screenreader testen
- Große Touch-Flächen verwenden
- Kontrast prüfen

#### Hauptbildschirm

- Farben nicht als einziges Merkmal verwenden
- Symbole ergänzen
- Akustische Hinweise einbauen

#### Tests

- Nur per Tastatur bedienen
- Mit Screenreader testen
- Farbfehlsichtigkeiten simulieren

### Ergebnis

Erste barrierearme Version des Spiels.

---

## Definition of Done

Das Projekt gilt als erfolgreich, wenn:

- Smartphones per QR-Code verbunden werden können
- mindestens 4 Personen gleichzeitig spielen können
- eine Spielrunde maximal 5 Minuten dauert
- das Spiel auf einer Messe einsetzbar ist
- Accessibility von Beginn an berücksichtigt wurde
- das Spiel Spaß macht und andere Mitarbeitende es freiwillig mehrfach spielen möchten
